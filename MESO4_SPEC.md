# MESO 4 — Program Spec v5 FINAL (post-audit) (6 exercises every session, project MEVs enforced)

Dates: Mon Aug 24 – Sun Oct 11, 2026 — 5 accumulation weeks. Bristol (Sep 17) shifts W4 D3/D4 to Mon/Tue Sep 21–22; W5 runs Sep 24–29; deload sessions Oct 1–4; beach Oct 5–11 = full rest. M5 starts Oct 12.
Phase: maintenance calories → full-width RP volume bands
Split: Upper A / Lower A / Upper B / Lower B, 4×/week, 6 exercises per session, 24 total
RIR wave (standard `WEEKS`): W1 4 → W2 3 → W3 2 → W4 2 → W5 0–1 → W6 deload (2 sets, 50% load, rest ≤75s). App advances by session, not date, so the Bristol gap just delays W4 D3/D4 — loads carry as logged.
Pressing: 10–15 reps, exhale-through-press / no Valsalva note stays on card. `rirCap` removed — presses follow the normal wave (guardrail passed its M3 test).

## Design rules applied
- Upper days: exactly one exercise per muscle — chest, back, side delts, rear delts, biceps, triceps. Chest and back at 5 sets per exercise (2 exercises/wk each = 10 = project MEV). RP is fine with 4–6 sets per exercise per session; beyond ~6 is where per-set return drops.
- Lower days: M3 structure unchanged (already 6).
- W1 volume = MEV floor. In-meso accumulation adds sets to existing exercises only, W3 and W5. Never carry W5 sets into next meso's W1 (resolves ROADMAP vs philosophy conflict, same as loads).
- Consolidation, not rotation: dropped Smith CGBP, Cable Fly, Cable Lat Pulldown, Landmine Row, Cable Lateral Raise. One true rotation: DB Lateral Raise replaces Cable Lateral Raise (cable version had no load path in M3).
- Trade-off stated plainly: chest and back go from 12 weekly sets in M3 to 10 (project MEV, not below). Delts and arms are the emphasis muscles this meso; rotate emphasis back to chest/back in M5.
- Time cap is a hard constraint (adherence > volume per the Helms hierarchy in the project docs). Upper days run FLAT at 24 sets — accumulation there is reactive (RP weekly add/hold/reduce loop), not scheduled: only add a set on delts/triceps at W3 if a muscle is visibly under-responding (no pump, no soreness, load stalling). Lower days carry the two cheap scheduled adds (leg extension +1 W3, hip thrust +1 W3). W5 always runs ~20% slower per set (M3: 2.4 → 3.0), so this keeps upper W5 at ~60.

## Post-audit adjustments (Aug 15)
Independent RP audit run against project files, chat history and public RP sources. Accepted: (1) emphasis muscles must actually ramp — +1 set at W3 on side delts (DB lat, X-body) and triceps (OH ext, pushdown), upper days 24→26 from W3 (~+4 min); (2) Smith presses stop at 1 RIR in W5 (bar-fall rule) — on the card note; (3) upright-row ROM cue on the card (wide grip, elbows lead, stop just below shoulder height — Schoenfeld/Kolber impingement guidance for a tall ex-thrower); (4) EZ curl W1 52.5→50. Rejected: audit's "Bayesian increment broken" — misread; app increments are cumulative targets and 90s-rest cables are on the iso track (→27.5 W5). Found on review: pulldown/row at 1:45 rest fell below the app's `rest>=120` compound threshold and would have progressed on the iso track (+5 by W5 vs +10) — rest restored to 2:00. Cable Rear Delt Fly kept per Blake's explicit call; chest-supported DB reverse fly on the incline bench is the recorded fallback. Change-budget critique acknowledged (this transition is >2 variables); accepted knowingly because time cap forced the structure change.

## App changes — implemented in patch_meso4.py (build-verified)
1. `MESO4_ROUTINES` — 24 exercises above, same field names as MESO3_ROUTINES. No `rirCap`. Pressing cards keep the exhale-through-press `note`.
2. New optional field `addSets: { 3: 1 }` — ExerciseCard renders `sets + adds for weeks ≤ current`; deload ignores it. Green banner shows the add. Ships on Leg Extension and Hip Thrust only; the mechanism is there for reactive upper adds.
3. New optional field `calibrationWeeks: [1]` — restricts the calibration banner to listed weeks (Cable Crunch W1 only). OH Ext, Leg Ext, Bayesian stay weekly.
4. Auto-reduce fix — for calibration exercises, next-week progression is computed on the non-failure sets and ignores the failure set's RIR (`avgWtX/avgRepsX` stored by `saveSessionPerformance`; DB fallback slices the last set too). This is what wrecked OH Ext in M3.
5. `MESOCYCLES` entry `rp-meso-4`, 2026-08-24 → 2026-10-11 (end date covers beach week so the app stays on Meso 4), `weeks: WEEKS`.
6. Meso selector strip collapses: current + previous shown, `‹` expands the rest. Scales to any number of mesos; History unchanged.
7. `Hanging Straight-Leg Raise` is new — the app auto-inserts it into `exercises` on first log (muscle_group Abs, cable_ratio 1). No SQL needed. DB Lateral Raise and Cable Rear Delt Fly (M1) already exist.

## Chin-ups vs lat pulldown — verdict (revised)
Pulldown. Blake's read of the log is right: with the thickest band, chin-ups sat at 6–8 reps every set including W5, and every set was effectively at failure — there's no RIR wave available on a movement you can only just do. RP rotates an exercise when it can't be progressed at the prescribed effort; that's this. Pulldown went 187.5→210×12 in M3 with clean 2.5 lb steps. Chin-ups come back later as a finisher/skill slot once BW pulling catches up. Stack ceiling caveat stands: if the pulldown maxes the stack, widen to 10–15 reps or go single-arm.

## Is 8 → 6 the wrong direction? — verdict
No. RP's landmarks are sets per muscle per week; exercise count is not a landmark. RP routinely programs one movement per muscle per session at 4–6 sets, and the project's own hierarchy puts adherence above volume. What would make it wrong is dropping a muscle below MEV — which v2 did for chest and back (8 vs the project's 10) and v3 corrects. Frequency stays 2×/wk for every muscle, which the RP doc calls sufficient for the MEV–MAV band.
